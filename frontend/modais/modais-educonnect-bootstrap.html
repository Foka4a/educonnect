Modais em Bootstrap

Os mesmos seis modais, agora com o componente Modal do Bootstrap 5.3 e as cores do guia de estilos aplicadas por variáveis CSS.

No seu projeto PHP: inclua o CSS e o JS do Bootstrap 5.3, copie o bloco “Tema EduConnect” para o seu CSS global e reutilize os .modal como includes. Abra com data-bs-toggle="modal" data-bs-target="#id"; o fechamento por Esc, clique fora e foco preso já vêm do Bootstrap. Para o tema escuro, use data-bs-theme="dark" no <html>.
